# CodeAlpha Internship — Frontend Development Tasks

This repository contains the tasks completed as part of the **Frontend Development Internship** at **CodeAlpha**.

**Domain:** Frontend Development
**Organization:** CodeAlpha

---

## 📁 Tasks

| # | Task | Description |
|---|------|--------------|
| 1 | [Image Gallery](./CodeAlpha_ImageGallery) | A responsive image gallery with a lightbox view, category filters, and the ability to add or delete photos. |
| 2 | [Calculator](./CodeAlpha_Calculator) | A calculator with all core arithmetic operations, keyboard support, and additional functions like square root and percentage. |

Each task folder includes its own `index.html` file and a dedicated README with full details on features and how to run it.

---

## 🛠️ Tech Stack

All tasks are built using **HTML, CSS, and vanilla JavaScript** — no frameworks, libraries, or build tools. Each project is a single, self-contained file that runs directly in a browser.

## ▶️ How to Run

Open the `index.html` file inside any task folder in a web browser. No installation or setup is required.

---

## 📌 About the Internship

This repository was created to fulfill the project submission requirements of the CodeAlpha Frontend Development Internship, which involves designing, building, and documenting real-world frontend projects.
