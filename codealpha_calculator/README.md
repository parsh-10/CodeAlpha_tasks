# CodeAlpha Calculator

A calculator built with HTML, CSS and vanilla JavaScript, with a clean dark UI and a few extra functions beyond the basics.

**Domain:** Frontend Development Internship
**Organization:** CodeAlpha

## Features

- All core arithmetic: addition, subtraction, multiplication, division
- Operator chaining (e.g. `5 + 3 × 2` computes correctly step by step)
- Extra functions: square root (√), square (x²), reciprocal (1/x), sign toggle (±), percent (%)
- Full keyboard support — digits, `+ - * /`, Enter/`=` to calculate, Backspace to delete, Esc to clear
- Live history strip showing the pending calculation above the main display
- Thousands-separator formatting as you type
- Handles edge cases cleanly (divide by zero, invalid operations) without breaking the UI
- Fully responsive layout

## How to run

Just open `index.html` in any browser — no build steps or dependencies.

## Tech stack

HTML5, CSS3 (Grid, custom properties, animations), vanilla JavaScript — no frameworks or libraries.
